## 데이터 흐름 — 사진 → 추천 카드

```
🎨 사용자 사진 업로드
  │
  ▼
⚙️ Express API: POST /api/analyze-image
  │  사진 수신 → LLM Vision 호출
  │  응답: { scene_tags, mood_tags, confidence, status }
  │
  ▼
📦 태그 표준화 (데이터 담당이 정의한 유사어 매핑표 적용)
  │  "바닷가" → "바다", "초원" → "목장" 등
  │
  ▼
⚙️ Express API: POST /api/recommend-from-tags
  │  표준 태그/레퍼런스 카드 수신 → 58개 장소 데이터셋 조회
  │
  ▼
📦 추천 점수 계산 (데이터 담당이 설계한 로직)
  │  - moodScore          → primaryTheme, mood_tags, sceneTags
  │  - conditionScore     → 목적, 접근성, 시간, 계절
  │  - routeDistanceBonus → 1번 카드 기준 거리 보정
  │  - exposure/coverage  → 최근 노출·균등 노출 보정
  │  - excludeIds         → 다시 추천 중복 방지
  │
  ▼
3장의 RecommendationCard 반환
  (최적 장면 / 같은 무드 대안 / 조건 맞춤)
  │
  ▼
🎨 results 화면 렌더링
  │
  ├─ ⚙️ KTO API → 장소 사진 fetch
  ├─ ⚙️ KTO API → 혼잡도 fetch
  └─ ⚙️ KTO API → 관광 정보 fetch
```

## Supabase places 테이블 — 핵심 컬럼

데이터 담당이 직접 구축·관리하는 고유 데이터셋 (KTO API 가공이 아닌 자체 DB).

| 컬럼 | 역할 |
|------|------|
| `mood_tags[]` | 추천 알고리즘의 핵심 매칭 키 (데이터 담당이 수동 표준화) |
| `scene_tags[]` | LLM 분석 결과와 매칭되는 장면 태그 |
| `accessibility` | 교통수단별 접근성 점수 기반 |
| `best_season` | 계절 점수 계산용 |
| `note` | 안전 위험 키워드 감점 기준 |
| `lat / lng` | Haversine 거리 계산용 |

현재 장소 DB 도시 범위는 16개 시·군, 총 58개 장소입니다.
