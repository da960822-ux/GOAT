## 패키지 구조 (pnpm Monorepo)

```
GOAT/
├── artifacts/
│   ├── api-server/          # Express 5 백엔드 서버
│   │   └── src/
│   │       ├── routes/      # API 라우트
│   │       ├── middlewares/ # 미들웨어
│   │       └── lib/         # 공통 유틸
│   │
│   └── goat-mobile/         # Expo 모바일 앱
│       ├── app/             # Expo Router 화면
│       ├── src/
│       │   ├── components/  # 재사용 컴포넌트
│       │   ├── services/    # API 호출 / 추천 알고리즘
│       │   ├── context/     # 전역 상태 (AppContext)
│       │   ├── hooks/       # 커스텀 훅
│       │   ├── types/       # TypeScript 타입
│       │   └── data/        # 정적 데이터 (43개 장소 JSON)
│       └── assets/          # 이미지, 폰트
│
└── lib/
    ├── db/                  # Drizzle ORM 스키마 (Supabase 연동)
    ├── api-spec/            # OpenAPI 3.1 스펙 (YAML)
    ├── api-zod/             # Zod 유효성 스키마 (자동 생성)
    └── api-client-react/    # React Query 훅 (자동 생성)
```

## 데이터 흐름 — 추천 요청

```
사용자
  │
  ├─ 감성 선택 + 조건 입력
  │
  ▼
AppContext (전역 상태 저장)
  │
  ▼
recommendationService.getRecommendations()
  │  (로컬 JSON 43개 장소 기반 스코어링)
  │  - scoreMood()        → 감성 일치도
  │  - scorePreferences() → 조건 일치도
  │  - safetyScore()      → 안전도
  │  - distanceBoost()    → 거리 보정
  │
  ▼
3장의 RecommendationCard 반환
  (장면 최적 / 내 상황 맞춤 / 안전한 대안)
  │
  ▼
results 화면 렌더링
  │
  ├─ KTO API → 장소 사진 fetch (usePlacePhoto)
  ├─ KTO API → 혼잡도 fetch (useVisitConcentration)
  └─ KTO API → 관광 정보 fetch (useTourInfo)
```

## 인증 흐름 (Supabase Auth)

```
앱 실행
  │
  ├─ Supabase 익명 세션 또는 소셜 로그인 (추후)
  │
  ▼
JWT 토큰 발급
  │
  ├─ 북마크 저장/조회 → Supabase REST API + RLS 적용
  └─ 추천 로그 저장 → recommendation_logs 테이블
```
