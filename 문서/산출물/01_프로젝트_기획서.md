# GOAT 프로젝트 기획서

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | GOAT (Greatest Of All Travels) |
| 개발 기간 | 2025.__ ~ 2025.__ |
| 팀 구성 | __명 |
| 플랫폼 | iOS / Android (React Native / Expo) |

## 2. 문제 정의

기존 여행 앱은 **장소 목록 나열** 방식이라 사용자가 스스로 골라야 함.  
→ "오늘 기분에 맞는 여행지가 어디야?" 라는 질문에 답해주는 앱이 없다.

## 3. 솔루션

감성(무드) 기반으로 강원도 여행지를 **3장의 카드**로 추천해주는 모바일 앱.  
사용자 위치, 동행 유형, 이동 수단, 방문 목적을 반영한 개인화 추천 제공.

## 4. 타겟 사용자

- 20~30대, 강원도 여행을 계획 중이거나 즉흥 여행을 원하는 사용자
- "어디 갈지 모르겠다"는 결정 피로 상태의 사용자

## 5. 핵심 기능

| 기능 | 설명 |
|------|------|
| 감성 선택 | 무드 카테고리(예: 잔잔한 일상, 웅장한 자연 등) 중 하나 선택 |
| 사진 무드 분석 | 내 사진을 업로드하면 감성 자동 분류 |
| 여행 조건 입력 | 동행(혼자/연인/친구/가족), 이동수단, 방문 시간, 목적 선택 |
| 3카드 추천 | 장면 최적 / 내 상황 맞춤 / 안전한 대안 카드 제공 |
| 장소 상세 | KTO 공공데이터 기반 사진·정보·혼잡도·카카오맵 연동 |
| 북마크 | 마음에 드는 장소 저장 |

## 6. 기대 효과

- 여행지 선택 시간 단축
- 감성 기반 탐색으로 만족도 향상
- 강원도 지역 관광 활성화

## 7. 기술 스택

| 영역 | 기술 |
|------|------|
| 모바일 앱 | React Native (Expo), TypeScript |
