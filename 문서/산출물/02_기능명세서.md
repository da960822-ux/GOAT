# GOAT 기능명세서

## 화면 목록 및 기능

### 1. 랜딩 화면 (`/`)

| 기능 | 설명 | 담당 |
|------|------|------|
| 히어로 이미지 표시 | 강원도 배경 이미지 + 앱 로고 | |
| 시작하기 버튼 | 감성 선택 화면으로 이동 | |
| 사진으로 시작 버튼 | 사진 무드 분석 화면으로 이동 | |

---

### 2. 감성 선택 화면 (`/mood-selection`)

| 기능 | 설명 | 담당 |
|------|------|------|
| 무드 카테고리 목록 | 감성 카드 리스트 표시 | |
| 카드 선택 | 단일 선택, 햅틱 피드백(모바일) | |
| 다음 버튼 | 여행 조건 입력으로 이동 | |
| 스텝 인디케이터 | 현재 단계(1/3) 표시 | |

**무드 카테고리 목록**

| ID | 감성명 |
|----|--------|
| serene | 잔잔하고 조용한 |
| majestic | 웅장하고 압도적인 |
| romantic | 감성적이고 로맨틱한 |
| healing | 치유와 휴식 |
| active | 활동적이고 신나는 |
| nostalgic | 감성적이고 레트로한 |

---

### 3. 사진 무드 분석 화면 (`/photo-mood`)

| 기능 | 설명 | 담당 |
|------|------|------|
| 사진 업로드 | 갤러리에서 사진 선택 | |
| 무드 자동 분류 | 이미지 분석 → 감성 카테고리 매핑 | |
| 결과 표시 | 분석된 감성 + 여행 조건 입력으로 이동 | |

---

### 4. 여행 조건 입력 화면 (`/travel-preference`)

| 기능 | 설명 | 옵션 | 담당 |
|------|------|------|------|
| 동행 선택 | 누구와 가는지 | 혼자 / 연인 / 친구 / 가족 | |
| 이동수단 선택 | | 자차 / 대중교통 | |
| 방문 시간 선택 | | 오전 / 오후 / 일몰 / 저녁 / 밤·새벽 / 무관 | |
| 목적 선택 | | 가볍게 산책 / 사진 위주 / 액티비티 / 조용한 휴식 | |
| 위치 입력 | 현재위치 / 지역 직접선택 / 건너뛰기 | | |
| 추천 받기 버튼 | 결과 화면으로 이동 | | |

---

### 5. 추천 결과 화면 (`/results`)

| 기능 | 설명 | 담당 |
|------|------|------|
| 3카드 추천 표시 | 장면 최적 / 내 상황 맞춤 / 안전한 대안 | |
| 추천 이유 표시 | 카드별 선택 근거 텍스트 | |
| 거리 표시 | 위치 제공 시 현재 위치에서 km 표시 | |
| 카드 클릭 | 장소 상세 화면으로 이동 | |
| 다시 추천 | 같은 조건으로 재추천 | |
| 처음으로 | 랜딩 화면으로 초기화 | |

---

### 6. 장소 상세 화면 (`/detail/[id]`)

| 기능 | 설명 | 담당 |
|------|------|------|
| 장소 사진 | KTO API 공식 사진 표시 | |
| 기본 정보 | 장소명 / 유형 / 주소 / 영업시간 | |
| 무드 태그 | 해당 장소의 감성 태그 배지 | |
| 혼잡도 예측 | KTO 방문 데이터 기반 혼잡도 표시 | |
| 관광 정보 | KTO 공식 설명 | |
| 카카오맵 연동 | 길찾기 버튼 → 카카오맵 앱 실행 | |
| 북마크 | 장소 저장/해제 | |
| 유사 장소 추천 | 비슷한 감성의 다른 장소 3개 | |

---

### 7. 공통 기능

| 기능 | 설명 | 담당 |
|------|------|------|
| 다크모드 | 시스템 설정 연동 | |
| 북마크 목록 | (탭) 저장한 장소 목록 | |
| 앱 정보 | 서비스 소개 / 데이터 출처 / 개인정보처리방침 | |
