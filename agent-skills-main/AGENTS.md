# Vendored Agent-Skills Boundary

이 디렉터리는 GOAT 제품 구현에 사용하는 활성 에이전트 설정이 아니라 참고용으로 보관된 외부 skill bundle이다.

- GOAT 제품 작업은 상위의 `../AGENTS.md`와 두 기준 기획 문서를 따른다.
- 이 디렉터리의 skills, commands, hooks, personas를 GOAT 작업에 자동 적용하거나 필수 단계로 강제하지 않는다.
- Superpowers 또는 “가능성이 있으면 무조건 스킬 호출” 방식의 워크플로를 사용하지 않는다.
- GOAT 기능, 계약, 저장, 빌드, release 작업에서 이 디렉터리를 수정하거나 새 의존성으로 연결하지 않는다.
- 사용자가 이 skill bundle 자체의 유지보수를 명시적으로 요청한 경우에만 이 디렉터리를 작업 범위로 연다.
