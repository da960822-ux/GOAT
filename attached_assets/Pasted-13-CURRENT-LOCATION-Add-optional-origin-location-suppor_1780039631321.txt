13. CURRENT LOCATION — Add optional origin/location support

Add an optional "현재 위치 사용" feature to improve recommendation realism.

Important UX rule:
- Do NOT request location permission on app launch.
- Do NOT request location permission on the landing screen.
- Only request location permission when the user taps "현재 위치 사용".
- Location must be optional. Users must be able to continue without it.

Where to add:
- Add an origin section in travel-preference.tsx.
- Section title:
  "어디서 출발하나요?"
- Subtitle:
  "가까운 감성 장소를 더 잘 추천해드릴게요."
- Options:
  1. 현재 위치 사용
  2. 주요 지역 선택
  3. 건너뛰기

Implementation:
- Use expo-location.
- If expo-location is not installed, install it with:
  npx expo install expo-location
- Request foreground location permission only when the user taps "현재 위치 사용".
- Do not use background location.
- Do not continuously track location.
- Get current location once and store it for the current recommendation flow.

Expected state shape:
origin: {
  type: "current" | "region" | "skip",
  latitude?: number,
  longitude?: number,
  regionName?: string
}

Permission handling:
- If permission is granted:
  - Get current coordinates.
  - Show a selected state such as "현재 위치 적용됨".
- If permission is denied:
  - Show a calm message:
    "위치 권한이 없어도 감성 추천은 계속 이용할 수 있어요."
  - Let the user choose 주요 지역 선택 or 건너뛰기.
- If location fetch fails:
  - Show:
    "현재 위치를 불러오지 못했어요. 지역 선택으로 대신할 수 있어요."
  - Do not block the flow.

Recommendation logic:
- Pass origin to getRecommendations.
- If origin has latitude/longitude and place coordinates exist:
  - Calculate approximate distance.
  - Use distance/accessibility as a soft ranking boost.
  - Do not let distance dominate mood matching.
- Suggested scoring weight:
  - mood/scene match remains the main factor
  - origin distance/accessibility should only adjust ranking slightly
- If origin is skipped or coordinates are missing:
  - Recommendation should work exactly as before.

Results screen:
- If current location was used, show a small condition chip:
  "현재 위치 기준"
- If distance can be calculated, show approximate distance:
  "약 12km"
- Do not make the UI look like a map/distance optimization app.
- Keep the emotional travel card feeling.

Privacy copy update:
- Update privacy.tsx to mention:
  "현재 위치는 가까운 장소 추천을 위해 사용되며, 사용자가 직접 권한을 허용한 경우에만 가져옵니다. 위치는 지속적으로 추적하지 않습니다."

App config:
- If app.json/app.config.ts needs permission text, add a natural Korean permission message:
  "GOAT가 가까운 감성 장소를 추천하기 위해 현재 위치를 사용합니다."

Do not add:
- background location
- live tracking
- route planning
- map screen
- distance-first sorting
- mandatory location permission
