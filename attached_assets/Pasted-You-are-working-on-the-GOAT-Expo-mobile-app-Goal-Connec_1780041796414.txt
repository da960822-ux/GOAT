7. Recommendation card output structure
==================================================

Each result card should output:

{
  role: "scene_best" | "similar_alternative" | "today_comfort",
  roleLabel: string,
  placeName: string,
  city?: string,
  primaryMood: string,
  imageUrl?: string,
  reason: string,
  photoPoint?: string,
  chips: string[],
  distanceText?: string,
  crowdingLabel?: string,
  weatherFitLabel?: string,
  sourceFlags?: string[]
}

Role labels:
- scene_best → "가장 닮은 장면"
- similar_alternative → "비슷한 감성의 대안"
- today_comfort → "오늘 가기 편한 선택"

Card 1: 가장 닮은 장면
Use:
- mood_tags
- primary_mood
- photo_point
- tourism photo keywords

Reason example:
"선택한 지중해 감성과 가장 가까운 흰 건물·오션뷰 장면을 가진 장소예요."

Card 2: 비슷한 감성의 대안
Use:
- overlapping mood tags
- similar photo point
- less crowding if available

Reason example:
"비슷한 바다마을 분위기를 유지하면서도 조금 더 여유롭게 둘러보기 좋은 대안이에요."

Card 3: 오늘 가기 편한 선택
Use:
- current location
- transport
- visitTime if selected
- weather
- accessibility
- visitor concentration

Reason example:
"오늘 조건에서는 이동 부담이 낮고, 짧게 들러도 장면을 남기기 좋은 선택이에요."

Do not use generic reasons:
- "조건과 잘 맞아요"
- "추천 조건에 부합합니다"
- "인기 있는 장소입니다"
