Improve GOAT’s usability and visual design.

Do not change the core logic.
Do not add backend, login, route planning, or new APIs.
Focus on UX clarity and travel-app visual quality.

Design references:
- Airbnb for emotional image-first cards and premium travel feeling
- Triple for travel preference flow and itinerary-style clarity
- Klook for scannable travel recommendation cards
- MyRealTrip for Korean travel app tone and category readability

Do not copy any app directly.
Use them only as UX references.

Usability improvements:

1. Landing screen
Show only two main actions:
- 감성으로 장소 찾기
- 사진으로 감성 찾기

Add clear subcopy:
“장소명을 몰라도 괜찮아요. 보고 싶은 분위기만 고르면 GOAT가 3곳으로 압축해드려요.”

2. Add progress indicator
Show the current step:
- 1/3 감성 선택
- 2/3 여행 조건
- 3/3 추천 완료

3. Mood selection screen
Make mood cards more visual and easier to scan:
- large mood title
- one-line emotional description
- 3 keyword chips only
- 2 example place names
- clear selected state
- sticky bottom CTA: “이 감성으로 계속하기”

4. Travel preference screen
Make it feel less like a survey.
Use one question section at a time or visually separated cards.

Questions:
- 누구와 가나요?
- 어떻게 이동하나요?
- 언제 가나요?
- 오늘 원하는 여행은?

Use large pill buttons.
Make selected state very clear.
Add sticky bottom CTA: “추천 카드 보기”

5. Recommendation result screen
Add selected condition summary at the top:
“선택한 조건”
Example:
“지중해·유럽 정원 감성 · 연인 · 자차 · 오후 · 사진 위주”

Show exactly 3 cards:
- 장면 최적
- 내 상황 맞춤
- 안전한 대안

Each card should be scannable:
- role badge
- place name
- one-line recommendation reason
- key info chips: 추천 시간, 추천 계절, 접근성
- primary CTA: 카카오맵에서 보기
- secondary text link: 자세히 보기

Do not overload the card with too many badges.

6. Place detail screen
Make it feel like a travel guide page:
- large header
- place name
- mood subtitle
- photo point card
- visit info card
- caution card
- same-mood alternatives
- sticky bottom CTA: 카카오맵에서 보기

7. Error and empty states
Add friendly messages:
- 추천 결과가 부족해요
- 조건을 조금 넓혀 다시 추천해볼게요
- 카카오맵을 열 수 없어 웹 지도로 연결할게요

8. Copywriting
Make all Korean UI text natural, short, and action-oriented.

Avoid technical labels.
Avoid long database-like text.
Use emotional travel copy.

Examples:
- “이런 장면을 찾고 있나요?”
- “오늘 조건에 맞춰 3곳을 골랐어요”
- “비슷한 감성을 더 여유롭게 즐길 수 있어요”
- “방문 전 운영 정보를 확인해주세요”

9. Visual polish
The app should feel like a Korean travel curation app, not a database app.

Use:
- white background
- deep violet primary
- lime accent
- soft lavender sections
- large readable Korean text
- rounded travel cards
- generous spacing
- fewer but stronger CTAs
- bottom sticky buttons
- safe-area friendly layout

Keep KakaoMap only.
Remove Naver Map and Tmap from the user-facing UI.
