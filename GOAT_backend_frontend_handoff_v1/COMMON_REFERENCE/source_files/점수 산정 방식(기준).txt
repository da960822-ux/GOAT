[점수 산정 기준]
-> 방문 무드 매칭(감성 선택)
-> 방문 조건 적합도
	(여행 목적(7가지),
	동행여부-점수부여X(혼자/친구/연인/가족),
	이동수단*(접근성: 자차/대중교통/도보중심),
	방문 시간대*,
	계절 적합도*)
-> 거리 조정(가산점)
------------------------------------------------------------------------
1. 방문 무드 매칭 baseScore 45점
- 사용자가 선택한 테마와 장소 primaryTheme이 같으면 18점
- mood_tags 일치:
  - 1개 일치: 6점
  - 2개 일치: 12점
  - 3개 이상 일치: 17점
- sceneTags 일치:
  - userSceneTags와 place.sceneTags 비교
  - 1개 일치: 5점
  - 2개 이상 일치: 10점

2. 방문 조건 적합도 baseScore 45점
- travelPurpose가 장소 purpose_tags에 있으면 16점
- 선택 이동수단 기준:
  - 상: 12점
  - 중: 7점
  - 하: 1점
- 방문 시간대:
  - 정확히 일치: 8점
  - 인접 시간대: 4점
  - 불일치: 0점
- 계절 적합도:
  - 현재 계절 포함: 9점
  - 사계절 포함: 7점
  - 불일치: 0점

3. 거리 조정 routeDistanceBonus 10점
거리 조정은 사용자 현재 위치 기준이 아니라 1번 카드 기준 연계 거리 보너스다.
1번 카드에는 적용하지 않는다.
2번/3번 카드에서만 적용한다.
1번 카드 장소와 가까운 후보일수록 가산점을 부여한다.
좌표가 없으면 routeDistanceBonus는 0점 처리한다.


[추천카드]
baseScore = 방문 무드 매칭 45점 + 방문 조건 적합도 45점 = 90점
routeDistanceBonus = 1번 카드 기준 연계 거리 보너스 최대 10점

1번 카드: 최적 장면 카드
- primaryTheme 일치 후보 중 baseScore 1위
- 거리 보정과 노출 보정은 적용하지 않음
- 사용자가 고른 무드에 가장 정직하게 맞는 장소

2번 카드: 같은 무드 대안 카드
- 1번과 같은 primaryTheme 후보 우선
- 1번과 같은 장소는 제외
- 같은 city는 허용
- 단, sceneTags/place_type이 너무 비슷하면 중복 페널티 적용
- 1번 카드 기준 연계 거리 보너스 반영
- 점수 차이 8점 이내면 더 가까운 후보 또는 덜 노출된 후보로 교체 가능

3번 카드: 조건 맞춤 카드
- travelPurpose, season_tags, best_time, accessibility 점수가 높은 후보
- primaryTheme이 달라도 가능
- 단, purpose_tags가 아예 안 맞으면 제외
- 1번 카드 기준 연계 거리 보너스 반영
