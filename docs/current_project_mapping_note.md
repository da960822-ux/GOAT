# 현재 프로젝트 반영 노트 v1.3_api_first_fallback

## 백엔드

- `seed_places_core43.sql`처럼 장소를 삭제한 seed 파일은 사용하지 않는다.
- DB에는 반드시 `seed_places_all58.sql`을 반영해 `GOAT-001 ~ GOAT-058` 전체를 넣는다.
- 추천 함수는 전체 seed 수를 `seedPoolSize: 58`로 유지한다.
- 실제 추천 계산 pool은 조건에 따라 달라질 수 있다.
  - `ALL58`: 58개 전체 후보.
  - `PRIMARY43`: confirmed + 비숙박/비리조트 43개 1차 방문지.
- `dataStatus === "confirmed"`만 무조건 남기는 필터는 금지한다.
- 숙소/료칸/리조트/카라반 태그가 들어오면 43개 필터를 적용하지 말고 `ALL58`을 사용한다.
- 같은 도시 최대 1개 제한은 제거했다. 같은 장면 대안이 같은 도시여도 점수가 높으면 추천될 수 있다.

## 프론트

- 기존 앱에 `gw001` 같은 구버전 ID 데이터가 있다면 최신 `GOAT-001` 형식과 충돌한다.
- 추천 화면은 mock/API 응답 기준으로 구현한다.
- `seedPoolSize`가 58인지 확인하면 전체 후보가 보존되는지 검증할 수 있다.
- `candidatePoolSize`는 조건에 따라 58 또는 43이므로, 무조건 58이어야 한다고 처리하면 안 된다.
- `poolPolicy`와 `adaptivePoolRetryUsed`는 디버그/QA 표시용으로 사용할 수 있다.
- 이미지와 좌표가 null이면 기본 이미지와 `mapSearchQuery` 검색 연결을 사용한다.

## 기존 프로젝트에서 반드시 교체할 부분

- 프론트/서비스 로직 안의 `confirmed만 사용` 조건.
- 숙소/리조트 무조건 제외 조건.
- 43개 고정 후보 수를 전제로 한 문구.
- 같은 도시 최대 1개 강제 제한.

## v1.3 추가 반영

- 프론트에서 자유 태그 조합보다 검증된 레퍼런스 카드 12개를 우선 노출한다.
- `청량함`, `이국적` 같은 추상 무드는 단독 추천 기준으로 쓰지 않고 moodExpansion 결과를 활용한다.
- `꽃밭`, `폐광`, `산`, `호수`, `발리`, `산토리니`는 단독 선택 카드로 쓰지 않는다.
- `adaptivePoolRetryUsed === true`는 오류가 아니라 PRIMARY43 결과가 약해 ALL58로 보강한 정상 동작이다.
