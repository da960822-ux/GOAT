# 데이터 결정 노트 v1.3_api_first_fallback

## 최종 결정

GOAT 장소 후보는 `GOAT-001 ~ GOAT-058` **58개 전체를 seed pool로 유지**한다.  
단, 서비스 상황에 따라 58개 중 **43개 1차 방문지 pool로 조건부 필터링**할 수 있다.

## 왜 이렇게 수정했는가

기존 제안서에는 “58개 seed pool + 43개 1차 추천 풀” 기준이 들어가 있었다.  
이번 수정 기준은 이를 삭제하거나 충돌시키는 것이 아니라 다음처럼 정리한다.

- 58개: 전체 후보 데이터이자 확장 가능한 seed pool.
- 43개: 일반 방문지/사진스팟 추천에서 쓰는 검증 완료 비숙박·비리조트 1차 pool.
- 숙소·료칸·리조트·카라반 감성이 들어오면 43개로 좁히지 않고 58개 전체에서 추천.
- future_candidate / needs_verification 장소도 특정 장면과 강하게 맞으면 58개 pool에서 추천 가능.

## pool 정책

| 정책 | 후보 수 | 기준 |
|---|---:|---|
| `ALL58` | 58 | 전체 seed pool. 숙소/료칸/리조트, 후보 장소, 확장 장면 포함 |
| `PRIMARY43` | 43 | `confirmed`이면서 숙박·리조트 성격이 아닌 일반 방문지 중심 |

## v1.2 태그 보강 결정 + v1.3 API-first fallback 유지

- 태그는 장면/무드/스타일/장소유형/활동/조건/의도/위험으로 분리한다.
- `숙소`, `료칸`, `리조트`는 장면 태그가 아니라 pool 전환용 intent 태그로 본다.
- `청량함`, `이국적`, `낭만적`, `탁트임` 같은 추상 무드는 `moodExpansion`으로 실제 장면 태그에 연결한다.
- 모든 태그 조합에 후보 3개를 보장할 수 없으므로, 약한 태그는 단독 노출하지 않고 레퍼런스 카드 조합으로 사용한다.
- PRIMARY43 결과가 약하면 `auto` 모드에서 ALL58로 한 번 재시도한다.

## API 응답 기준

- `seedPoolSize`: 전체 seed 후보 수. 정상 데이터라면 58.
- `candidatePoolSize`: 실제 추천 계산에 사용한 후보 수. 조건에 따라 58 또는 43.
- `poolPolicy`: `ALL58` 또는 `PRIMARY43`.
- `poolReason`: 왜 해당 pool이 선택되었는지 설명.
- `adaptivePoolRetryUsed`: PRIMARY43 결과가 약해서 ALL58로 재시도했는지 여부.

## 제안서/발표자료 수정 문구

초기에는 58개 전체 후보를 추천 seed pool로 유지하고, 사용자의 요청 조건에 따라 검증 완료 일반 방문지 중심의 43개 1차 pool로 좁혀 추천할 수 있다. 숙소·료칸·리조트 감성이나 후보 장소와 강하게 맞는 장면은 58개 전체 pool에서 추천하며, `data_status`에 따라 검증 완료·후보 장소·운영 확인 필요 배지를 다르게 표시한다.

## 주의

이미지 URL, 주소, 좌표는 아직 null일 수 있다.  
따라서 MVP에서는 이미지 기본값과 `mapSearchQuery` 기반 지도 검색을 사용한다.
