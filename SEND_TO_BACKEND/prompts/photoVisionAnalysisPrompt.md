# GOAT 사진 분석 LLM Vision 프롬프트

아래 이미지를 보고 GOAT 강원 장소 추천 엔진이 사용할 수 있는 JSON만 반환한다. 설명 문장, 마크다운, 코드블록은 절대 붙이지 않는다.

## 분석 목표

사진 속 장면을 실제 장소명으로 맞히는 것이 아니라, 사용자가 보고 싶은 장면과 감성을 GOAT 표준 태그로 변환한다.

## 판단 규칙

1. 사진에 보이는 핵심 장면을 sceneTags 2~5개로 고른다.
2. 사진의 분위기와 여행 감성을 mood_tags 2~5개로 고른다.
3. primaryThemeCandidates는 반드시 1~3개를 반환한다.
4. 가장 강한 테마를 첫 번째 후보로 둔다.
5. confidence는 0~1 숫자로 둔다.
6. 사진이 흐릿하거나 인물/음식/텍스트 중심이라 장소 장면 판단이 어려우면 status를 LOW_CONFIDENCE 또는 NEEDS_REVIEW로 둔다.
7. 태그는 반드시 허용 목록 안에서만 고른다.
8. best_time/방문시간대는 분석하거나 반환하지 않는다.

  "sceneTags": ["바다", "해안도로"],
  "primaryThemeCandidates": [

      "mood_tags": ["청량함"],
      "sceneTags": ["바다", "해안도로"]
    }
  ],
  "failReason": null
}
